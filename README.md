## ✨ المزايا

### 📖 الخطة الذكية
- خطة مراجعة تلقائية **لا تتجاوز دورتها ١٠ أيام**، تتكيف يوميًا مع إنجازك الفعلي.
- تركيز دائم على **الصفحات الضعيفة** أولًا (منع النسيان بفواصل متدرجة).
- تقييم كل جلسة (أتقنتها / جيدة / صعبة) يُعيد ترتيب أولويات الغد تلقائيًا.
- لوحة «تحتاج انتباهك» تُظهر الصفحات المُرشّحة للمراجعة، مع زر يفتح الصفحة مباشرة في المصحف.
- وِرد يومي بأزرار سريعة، وانتقال مباشر من المهمة إلى موضعها في المصحف («اذهب للوِرد»).

### 📜 المصحف الشريف
- **المصحف كاملًا** (٦٠٤ صفحات) بنص عثماني (نسخة quran-uthmani) — بيانات محلية داخل التطبيق، بلا أي طلب شبكة.
- تنقل حر: أزرار + شريط تمرير + قائمة سور + أسهم لوحة المفاتيح.
- وضع الوِرد: شريط أخضر يُبرز صفحات وِرد اليوم مع رقائق تنقل سريع.
- **ثلاثة أنماط قراءة**: عادي / ورقي (ورق المصاحف) / ليلي (مريح للعين) — تُحفظ للجلسة القادمة.
- **استئناف تلقائي**: يحفظ آخر صفحة قرأتها ويعود إليها عند فتح التطبيق.
- تكبير الخط بثلاث درجات.

### ⚖️ المتشابهات
لكل آية زر «متشابهات» يفتح لوحة تحفة:
- **من خبرة الحفّاظ** (تركواز): ٦٧٣ مجموعة منسّقة يدويًا من عمل **القارئ إدريس العاصم رحمه الله** — المواضع التي يخطئ فيها الحفّاظ عادة، مع دعم مقاطع متعددة الآيات وإشارة «السياق» (تكملة ما بعد المقطع للتمييز).
- **متطابقات** (أخضر): الآيات المتكررة حرفيًا مع أزرار قفز فوري.
- **متشابهات خوارزمية** (كهرماني): كشف آلي (تطبيع حرفي + LCS) مع **إبراز كلمات الاختلاف** في كل نظير.

### 🔊 التلاوة
- تلاوة لكل آية، أو **«استمع للصفحة»** بتسلسل تلقائي ينتقل للآية التالية.
- خمسة قرّاء: العفاسي، الحصري، المنشاوي، السديس، الدوسري.
- إبراز الآية الجارية داخل نص الصفحة.
- التلاوات تُحفظ في ذاكرة التطبيق بعد أول تشغيل — **تعمل بعدها دون إنترنت**.

### 📴 الأوفلاين
- PWA كامل: تثبيت من المتصفح كتطبيق مستقل.
- **كل شيء يعمل بلا إنترنت**: المصحف، المتشابهات، الخطة، التقدم — وحتى التلاوات المسموعة سابقًا.
- حالة التطبيق: لقطة محلية + **قائمة انتظار** تُرسل إجراءاتك تلقائيًا عند عودة الاتصال.
- خطوط محلية بالكامل (بلا Google Fonts) — أساس متين للتحويل إلى تطبيق هاتف.

## 🛠️ التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 16 (App Router) + React 19 + TypeScript |
| الواجهة | Tailwind CSS 4 + shadcn/ui (New York) + Lucide |
| الخطوط | Amiri Quran / Amiri / Tajawal — **ملفات woff2 محلية** |
| قاعدة البيانات | Prisma + SQLite |
| الأوفلاين | Service Worker + Cache API + localStorage |
| الصوت | everyayah.com (روابط مجانية ثابتة، تخزين محلي بعد أول تشغيل) |

## 🔬 ملاحظات هندسية

- **ترقيم بيانات العاصم**: مطلق 0-based (1:1 = 0) — سكربت الدمج يحوّله عبر فهرس مبني من بياناتنا نفسها، ثم يوحد الأزواج المسجلة بالاتجاهين (675 زوجًا مدموجًا) ويُبقي علم «السياق» أياً كان مصدره.
- **كاش التلاوات**: عامل الخدمة يتجاهل ترويسة `Range` ويطلب الملف كاملًا (200) — تُخزَّن نسخة كاملة واحدة تعمل أوفلاين.
- **فصل البسملة**: النسخة العثمانية تدمج البسملة في أول آية من كل سورة — يُفصل تطبيع يشمل تحويل `ٱ` (U+0671).

## 📱 تطبيق الجوال — نسخة تعمل بلا إنترنت

توجد نسخة أندرويد كاملة من وِردي تعمل **بدون إنترنت إطلاقاً**: نفس المحرك والخطة والمصحف والمتشابهات والتفسير، لكن البيانات كلها داخل التطبيق (بلا خادم) — تقدمك يُحفظ في جهازك مباشرة.

- **التحميل**: حمّل `wirdi-offline-v*.apk` من [صفحة الإصدارات](https://github.com/mohamed21abdelrazek/quran/releases) وثبّته على هاتفك.
- **البناء محلياً**: `bash scripts/build-offline.sh` ثم `bash android-shell/build-apk.sh` (يتطلب Java 21 و Android SDK).
- **كيف تعمل؟** المعمارية نفسها للموقع والتطبيق؛ عند بناء الأوفلاين (`WARDI_OFFLINE=1`) تُستبدل وحدتان فقط:
  - `@/lib/db` ← `db-offline.ts`: نفس واجهة Prisma لكن فوق `localStorage` في جهازك.
  - `@/lib/client-backend/entry` ← `offline.ts`: نداءات محلية بدل طلبات HTTP.
  النتيجة تصدير ثابت يُغلَّف في WebView عبر Capacitor، ويُنشر تلقائياً إلى Releases عند كل دفعة عبر GitHub Actions.
- التلاوات الصوتية فقط تحتاج اتصالاً أول مرة لكل آية ثم تُخزَّن وتعمل أوفلاين.
